# 指標與超參數的解讀

| 指標 | 定義 | 本次狀態 |
| --- | --- | --- |
| 四tile座標衍生R@1 | 預測座標和標註座標對應同一張鄰接tile | 已計算93.66%，適用於本報告評估條件 |
| LSR@r | 每幀定位誤差不超過r公尺的比例 | 已計算 |
| MLE | 每幀定位距離誤差的平均 | 已計算 |
| SR@20 | 完整導航在規定終止條件下到達目標20m內的比例 | N/A |
| SPL | 導航成功指標乘上最短可行路徑長度／實際行進長度的效率比例，再取平均 | N/A |
| NE | 導航終止時真實位置到目標的距離 | N/A |

目前資料是固定影像序列；模型位置偏離不會改變下一張觀測。因此，不能把讀完整條影像序列當作導航成功，也不能把估計位置折線當作實際飛行路徑。有效導航數據需要可依動作產生新觀測的環境、controller、明確heading來源及一致的終止規則。這個架構可作導航定位模組，但本次沒有有效導航rollout，故三項導航指標保留N/A。

InfoGeo主要分析slot數K、融合權重α及頻譜維度r，並未使用Mean Shift頻寬。本次選擇FieldAnchor實際具有的參數：空間頻寬、分數溫度、迭代次數、密度權重。

固定候選曲線只重新解碼同一批36個候選及其分數；完整tracker bandwidth表則重新執行整條路線。兩者都未重新訓練。分數已包含原始位置參考及Kalman先驗，不能稱作純視覺相似度。

3次迭代後的精度改善很小，計算時間仍會增加；mode-density權重在這批資料的結果基本持平。不同測量條件的時間不可直接與其他稿件或端到端速度比較。

資料來源核對：原始逐幀數據與保存候選／分數逐筆一致，原7m設定重播的位置差異為0。
